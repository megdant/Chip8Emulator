************
*Guidelines*
************

Create a CPU emulator for the Chip-8 processor. 
The Chip-8 is a processor from the 70's that is an excellent introduction to hardware emulation as 
it has a limited instruction set and is very well documented. 
Write the emulator from scratch.

1. Research Chip-8; gather data sheets / instruction set info; gather some sample Chip-8 ROMs.
2. Create a disassembler and make sure it produces sensible output for a known good ROM.
3. Emulate the CPU (i.e. handle sequences of opcodes with your virtual processor).
4. Emulate the peripheral devices like user input, sound / video output. 

Emulator Requirements:
The emulator will be able to...
1. Disassemble a Chip-8 ROM and produce source assembly listings.
2. Execute a Chip-8 ROM without crashing.
3. Accept user input via keyboard and produce a graphical display.
